# dealfinder-beta4
Project 2 app/website development for Group Beta 4.
App Name:	Deal Finder
App Type:	Discount/Sales finder for video games
Problem It Solves:	This app would help users find sales and discounts from across various websites and combines them into one platform. Users can use social media features to find trending games, forums to communicate with other users, and price history to see past pricing. 

Page 1 — The first page the user will see when clicking on our website. Includes the hero page and buttons that are connected to other pages of the website.
Page 2 — The main page where discounts will be featured. Users can see current sales, past prices, and featured games.
Page 3 — This page allows users to connect with others through forums and chat-rooms in order to discuss games or topics of interest.
Page 4 — This page showcases games that are trending across multiple social media platforms, provides rankings and most popular game lists, and offers videos that give more information on games that are popular at the moment.
Page 5 — Social Media
Page 6 — All games page; Includes the price, platform, and game information for all games included in the website. Clicking on a thumbnail for a game will take the user to the main page for an individual game.

Key Interactive Feature 1:	Paths to all sections of the website, but specifically, a section where trending games and top discounts are featured.
Key Interactive Feature 2:	Highlights current and past pricing in order to give users a better idea of the game’s pricing history.
Key Interactive Feature 3:	An online forum that lets you talk to others about your favorite games as well as learn more about unfamiliar game titles from others experiences.
